# Визуальные процессы агентов — 2 октября 2026

## Что реализовано

Раздел «Агенты» получил кнопку «Пустая схема» и отдельную вкладку «Визуальная схема». Canvas на React Flow поддерживает перемещение узлов, соединения, масштабирование, удаление связей клавиатурой и настройку переходов через формы. Настройки узла расположены рядом со схемой; на мобильном экране — под ней. Положение узлов сохраняется. Черновик восстанавливается после перехода между вкладками, ошибка сохранения не отображается как успех. Версия графа защищает от перезаписи из устаревшей вкладки.

Доступны AI-задача с выбором модели из каталога сервиса, поиск, чтение сайта браузером, HTTP API, условия, согласование, ожидание, уведомление, WordPress, файлы, изображения, AI-проверка и завершение. Интеграционный процесс может работать без вызовов LLM и без начисления стоимости LLM. Пустой процесс автоматизации блокируется до сохранения узлов.

Поле описания задачи предлагает схему из доступных типов. Пользователь сначала видит предложение и стоимость, затем применяет и сохраняет его. Генерация схемы не запускает процесс. Повторный запрос с тем же ключом идемпотентности возвращает сохранённый результат, а не выполняет повторную платную генерацию. Ключ связан с пользователем и содержимым запроса.

## Интеграции и исполнение

HTTP-подключение создаётся в «Интеграциях»: публичный HTTPS URL, необязательный Bearer-токен, проверка подключения и привязка к агенту. Узел выбирает привязанное подключение, GET/POST, относительный путь и JSON-тело. Подстановки `{{objective}}` и `{{previous_text}}` передают данные без выполнения кода. Токен остаётся на backend. POST требует согласования конкретного тела запроса. Завершённый шаг не повторяется; при неопределённом результате POST автоматического повтора нет, пользователь получает сообщение о проверке внешнего сервиса.

Браузерный узел использует настоящий Chromium для чтения публичной страницы и поиска указанного текста. Это режим чтения: JavaScript, дополнительные сетевые запросы, загрузки, формы и авторизованные сессии отключены. Сеть проверяет все DNS-адреса и привязывает запрос к проверенному публичному IP; каждый перенаправленный URL проверяется заново. HTTP-запрос с токеном не следует перенаправлению. Есть ограничения времени и размера ответа.

Граф исполняется с явно сохранёнными переходами. Разрыв связи не превращается в неявный следующий шаг. Циклы запрещены; переходы сортируются перед сохранением, начальный узел сохраняется. Выбранная LLM проверяется на доступность, существующий механизм учёта стоимости сохранён.

## Проверки

- 40 тестов конфигурации и runtime графов, согласования, публикации и новых инструментов прошли; дополнительный тест пустой автоматизации также прошёл (41 уникальная проверка в этом наборе).
- 15 frontend-тестов надёжности чата и графа прошли.
- Production-сборка Next.js и TypeScript прошла.
- Браузерные сценарии проверяют ручную сборку, выбор модели, сохранение и удаление связей, JSON, ошибки backend, восстановление черновика, предварительное предложение по тексту и мобильный экран. Регрессия браузерного интерфейса чата также прошла.
- Настоящий Chromium проверен на контрольном HTML с поиском текста; транспорт сайта в этой проверке заменён контролируемым ответом.
- Django system check и проверка отсутствия незаписанных миграций прошли. FastEmbed/ONNX теперь импортируются только при построении embedding-модели, а не при обычном запуске Django.

Тесты внешних API и LLM использовали подменённые ответы. Реальные клиентские ключи, списания, внешние сервисы, PostgreSQL/Redis под нагрузкой и production-развёртывание здесь не проверялись. Общий прежний набор тестов чата имеет отдельно зафиксированные нерешённые падения; эта работа не означает исправность всего репозитория.

## Развёртывание

1. Пересобрать backend-образ: Dockerfile устанавливает Playwright и Chromium с системными зависимостями. Перезапустить web и workers на одном новом образе.
2. Выполнить `python manage.py migrate`: добавлены HTTP-тип подключения и таблица операций планировщика.
3. Пересобрать и перезапустить frontend с обновлённым lockfile.
4. Проверить новый пустой процесс, привязку тестового API, чтение публичной страницы и платный LLM-шаг на тестовом аккаунте.

Без Docker Chromium нужно установить командой `python -m playwright install --with-deps chromium`; доступность браузера проверяется до запуска агента. Можно задать `AGENT_BROWSER_EXECUTABLE` и `PLAYWRIGHT_BROWSERS_PATH`.

Это основа редактора в стиле n8n, а не полный каталог n8n: HTTP GET/POST и имеющиеся интеграции, последовательные ветви без циклов/параллельных ветвей, браузер только для чтения публичных страниц. OAuth-каталог, вебхуки и полноценное управление авторизованным браузером в эту версию не входят. CI/Actions не добавлялись. Production не развёрнут в этой сессии.
