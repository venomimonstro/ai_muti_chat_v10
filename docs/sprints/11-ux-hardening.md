# Sprint 11 — UX hardening и пользовательская полнота

## Цель

Превратить технический чат-контур Sprint 0–10 в рабочий B2C-продукт: закрыть поиск, историю, черновики, управление расходами, настройки аккаунта, мобильный сценарий, доступность и честные состояния ошибок.

## Реализовано

- изолированный API поиска по доступным пользователю чатам, сообщениям, проектам и файлам;
- серверный черновик на разговор с версией и локальный fallback в браузере;
- настройки low-balance порога, дневного и месячного лимитов расходов;
- проверка лимитов внутри транзакции резервирования средств;
- дедуплицированные low-balance уведомления после фактического списания;
- API центра уведомлений с read/read-all действиями;
- настройки продукта и биллинговых уведомлений;
- смена пароля с сохранением активной сессии и завершение всех сессий;
- API обращений в поддержку с административным контуром обработки;
- метаданные генерации в сообщении: модель, провайдер, токены, стоимость, correlation ID;
- отмена SSE-генерации с освобождением резерва и сохранением partial output;
- новый Next.js интерфейс поверх реальных API: auth, история, модель, проект, файлы, баланс, уведомления, настройки, поддержка и детализация стоимости;
- сочетания клавиш: `Ctrl/Cmd+K` — поиск, `Alt+N` — новый чат, `Enter` — отправка, `Shift+Enter` — новая строка;
- responsive mobile navigation, drawers, safe-area composer и PWA manifest/service worker;
- skip-link, focus-visible, aria labels/live regions, reduced motion;
- состояния loading, empty, low balance, retry/fallback, partial response и connection error.

## Инварианты

1. Поиск никогда не возвращает недоступные пользователю сущности.
2. Лимиты учитывают завершённые списания и активные резервы.
3. Прерванный клиентом стрим освобождает полный резерв; частичный текст сохраняется.
4. Ошибка провайдера не выдаётся за успешный ответ и не списывает деньги.
5. Все критические функции доступны на мобильном экране и с клавиатуры.

## Проверка

- Ruff и проверка отсутствия незаписанных миграций;
- backend test suite, включая ACL поиска, черновики, лимиты и отмену стрима;
- ESLint;
- production Next.js build и генерация PWA manifest.
