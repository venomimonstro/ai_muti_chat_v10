# Политика оплат и возвратов — шаблон для юридической проверки

## Пополнение
Баланс пополняется через подключённого платёжного провайдера. Зачисление происходит только после подтверждения успешного платежа провайдером и фиксируется в неизменяемом ledger сервиса.

## Списание
Для AI-запросов средства предварительно резервируются в пределах рассчитанного лимита. После успешного завершения операции списывается фактическая стоимость согласно зафиксированному pricing snapshot. При ошибке до завершения неиспользованный резерв освобождается.

## Возврат
Запрос на возврат рассматривается в соответствии с применимым правом, публичной офертой и фактически оказанным объёмом услуги. Технически возврат выполняется только по успешному платежу, с идемпотентностью и сверкой суммы с платёжным провайдером.
