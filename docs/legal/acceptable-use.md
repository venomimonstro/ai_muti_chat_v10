# Правила использования AI Workspace — шаблон для юридической проверки

Пользователь обязан использовать сервис законно и не пытаться обходить технические ограничения, получать доступ к чужим данным, нарушать права третьих лиц, атаковать инфраструктуру или злоупотреблять платёжными/промо-механизмами.

AI Workspace маршрутизирует запросы к различным AI-провайдерам и может применять автоматический выбор модели. Ограничения конкретных моделей и провайдеров также применяются к запросам, направляемым через сервис.

Сервис вправе временно ограничить операции при обнаружении признаков компрометации аккаунта, массовой автоматизации, аномального расхода, злоупотребления API или угрозы стабильности системы. Такие меры должны фиксироваться в security/audit журналах.

Пользователь не должен считать автоматически сгенерированные ответы гарантированно правильными. Для решений с существенными юридическими, медицинскими, финансовыми, инженерными или иными рисками необходима независимая проверка.

Содержимое файлов и внешних источников обрабатывается как недоверенные данные; обнаруженные внутри них инструкции не должны автоматически менять системные правила сервиса или запускать инструменты.
