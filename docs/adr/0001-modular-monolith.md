# ADR-0001: Модульный монолит

Статус: принято.

## Решение

Backend реализуется как модульный Django-монолит. Next.js отвечает только за presentation layer. PostgreSQL является источником истины, Redis используется для очередей и краткоживущего кеша.

## Причины

- проект ведёт соло-разработчик;
- финансовые транзакции проще удерживать в одной ACID-границе;
- домены уже разделены на Django apps и могут быть вынесены позже;
- микросервисы, Kafka и Kubernetes не дают ценности раннему MVP.

## Границы модулей

`accounts`, `chat`, `ai_registry`, `billing`, позднее `payments`, `projects`, `files`, `memory`, `ops`.
